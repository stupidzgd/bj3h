# 项目简介

本项目是一个基于 `React` 和 `Ant Design` 的后台管理系统，目前开放了以下功能：

## 开放功能

- **用户登录**：基于数据库的用户认证系统，支持管理员账号登录
- **权限验证**：基于角色的权限控制
- **动态路由**：根据用户权限动态生成路由
- **全局功能**：动态侧边栏、动态面包屑、Screenfull全屏、自适应收缩侧边栏
- **Excel 功能**：导出excel、导入excel、前端可视化excel
- **Zip 导出**：支持导出zip文件
- **错误页面**：404错误页面
- **组件**：拖拽列表
- **表格**：数据表格展示
- **Dashboard**：数据看板
- **引导页**：系统使用引导
- **ECharts 图表**：数据可视化图表
- **剪贴板**：复制功能
