# 移动端适配维护指南

## 1. 概述

本文档提供了项目移动端适配的维护指南，包括适配方案、实现方式、使用方法和维护规范。

## 2. 适配方案

项目采用了以下移动端适配方案：

### 2.1 媒体查询

使用CSS媒体查询实现响应式布局，针对不同屏幕尺寸应用不同的样式。

### 2.2 设备检测

使用JavaScript实现设备检测，用于在需要时进行条件渲染。

### 2.3 响应式组件

针对移动端特点，对部分组件进行了专门的适配，如导航菜单、表格、图表等。

## 4. 样式规范

### 4.1 媒体查询断点

| 断点名称 | 屏幕宽度 | 设备类型 |
|---------|---------|----------|
| xs      | ≤ 768px | 移动设备 |
| sm      | 769px - 992px | 平板设备 |
| md      | 993px - 1200px | 小桌面 |
| lg      | > 1200px | 大桌面 |

### 4.2 移动端样式添加规范

1. **新增移动端样式**：
   - 在 `_components.less` 文件中添加组件的移动端样式
   - 使用 `@media (max-width: @mobile-breakpoint)` 包裹移动端样式

2. **修改现有样式**：
   - 优先使用媒体查询覆盖现有样式
   - 避免直接修改基础样式，确保PC端显示不受影响

3. **样式命名规范**：
   - 移动端特有样式使用 `mobile-` 前缀
   - 响应式样式使用 `responsive-` 前缀

### 4.3 变量使用

在移动端样式中，优先使用 `_variables.less` 中定义的变量，如：

- `@mobile-breakpoint`：移动设备断点
- `@mobile-font-size`：移动端字体大小
- `@mobile-padding-*`：移动端间距

## 5. 组件适配

### 5.1 导航菜单

- 移动端使用抽屉菜单（MobileDrawer组件）
- PC端使用侧边菜单（Sider组件）
- 根据屏幕尺寸自动切换

### 5.2 表格

- 移动端表格支持横向滚动
- 优化表格列宽和内容显示
- 调整表格操作按钮大小

### 5.3 图表

- 图表自动调整大小
- 优化图表交互方式
- 添加手势操作支持

### 5.4 表单

- 优化表单元素大小和间距
- 确保输入体验良好
- 适配移动端键盘

## 6. 设备检测工具

### 6.1 常用方法

- `isMobile()`：检测是否为移动设备
- `isIOS()`：检测是否为iOS设备
- `isAndroid()`：检测是否为Android设备
- `isSmallScreen()`：检测是否为小屏幕（移动设备）
- `getBreakpoint()`：获取响应式断点

### 6.2 使用示例

```javascript
import { isSmallScreen, isMobile } from '@/utils/device';

// 条件渲染
if (isSmallScreen()) {
  // 移动端逻辑
} else {
  // PC端逻辑
}
```

## 7. 性能优化

### 7.1 代码分割

项目使用 React Loadable 进行代码分割，减少初始加载时间。

### 7.2 渲染优化

- 使用防抖函数减少不必要的渲染
- 优化图表组件的渲染性能
- 避免在移动端加载不必要的资源

## 9. 测试

### 9.1 测试方法

- 使用浏览器开发者工具模拟不同设备
- 在真实设备上测试
- 测试不同浏览器

### 9.2 测试重点

- 布局是否正确适配
- 交互是否流畅
- 功能是否完整
- 性能是否达标

## 10. 维护指南

### 10.1 新增功能

- 确保新功能在移动端和PC端都能正常工作
- 为新组件添加移动端适配样式
- 测试新功能在不同设备上的表现

### 10.2 样式修改

- 修改样式时考虑移动端适配
- 测试样式修改对移动端的影响
- 保持iOS和Android端的一致性

### 10.3 问题排查

- 检查设备检测是否正确
- 检查媒体查询是否生效
- 检查组件适配是否完整

## 11. 总结

本项目的移动端适配采用了媒体查询和设备检测相结合的方案，确保在iOS和Android设备上都能正常运行，同时保持与PC端的功能一致性。通过合理的样式组织和组件适配，实现了良好的移动端用户体验。

维护人员在添加新功能或修改现有功能时，应遵循本文档的规范，确保移动端适配的完整性和一致性。
